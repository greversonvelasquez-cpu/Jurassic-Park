# Jurassic Park: site turístico

Trabalho integrado do curso de Informática para Internet (ETEC Parque Belém). Site turístico sobre o parque de Jurassic Park, com páginas para visitantes, áreas técnicas, origem do parque, curiosidades, documentação, relatório técnico e um app de quiz.

## Páginas

- `index.html`: início
- `areas_visitantes.html`: áreas abertas aos visitantes
- `areas_tecnicas.html`: áreas técnicas do parque
- `origem.html`: como o parque nasceu
- `curiosidades.html`: curiosidades
- `documentacao.html`: documentação
- `relatorio-tecnico.html`: relatório técnico das espécies
- `app.html`: app de quiz (com download do `.apk` e do `.aia`)

## Tecnologias

HTML, CSS e JavaScript.

## Estrutura

```
index.html e demais páginas
css/        folha de estilo
js/         JavaScript do menu e dos formulários
imagens/    imagens do site
app/        arquivos do app de quiz
```

## Como abrir

Baixe o repositório e abra o `index.html` no navegador.
